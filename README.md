# BigFloat

This module is based on the [BigNumber](https://github.com/shoyguer/big-number) GDExtension addon by Lucas "Shoyguer" Melo (MIT), which is itself based on [GodotBigNumberClass](https://github.com/ChronoDK/GodotBigNumberClass) by ChronoDK. Integration of [libbf](https://bellard.org/libbf/) is planned to improve numerical precision.
